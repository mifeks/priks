Как начать

1. Запусти сервер

На своём компьютере или на виртуальной машине. В окне появятся адреса.

2. Открой клиент

Впиши адрес сервера, придумай ник и пароль, нажми «Создать ник».

3. Позови друзей

Они открывают тот же адрес в браузере или ставят клиент и создают свои ники.

Веб-версия открывается по адресу твоего сервера, например https://priks.твойдомен.ru. Телефон и ПК видят один и тот же чат — отдельная установка не нужна.

Что внутри

  • Сервер на Node.js без внешних зависимостей — один файл server.js
  • Веб-клиент на чистом HTML, CSS и JavaScript
  • ПК-клиент на WinForms, .NET Framework 4.8
  • Данные в одном файле store.json: пользователи, друзья, сообщения
  • Пароли — SHA256 с солью, сессии — случайные токены
