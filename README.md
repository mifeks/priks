# Прикс

Мессенджер без регистрации: только ник и пароль, общий чат и личные сообщения.
Сервер поднимается на своём компьютере или на виртуальной машине, данные лежат
в одном файле.

## Что в репозитории

| Папка | Что внутри |
|---|---|
| `server-node/` | Сервер для Linux/Windows на Node.js, без внешних зависимостей |
| `web/` | Веб-версия мессенджера: HTML, CSS, JavaScript |
| `site/` | Сайт для скачивания ПК-версии |
| `deploy/` | Инструкция для Yandex Cloud, служба systemd, конфиг nginx |
| `src/` | Исходники прежней версии: сервер и ПК-клиент на C# (.NET Framework) |
| `bin/` | Собранные `priks-server.exe` и `priks.exe` |
| `web-legacy/` | Старый веб-интерфейс, до переделки |

## Быстрый старт на своём компьютере

Нужен Node.js 18 или новее.

```bash
cd server-node
node server.js
```

Сервер напечатает адреса:

```
Прикс-сервер слушает 0.0.0.0:8777
http://127.0.0.1:8777/        — на этом компьютере
http://192.168.x.x:8777/      — для телефона в той же сети
```

Открыть адрес в браузере, придумать ник и пароль, нажать «Создать ник».

Порт и папки можно переопределить переменными окружения:

```bash
PORT=9000 WEB_DIR=../web DATA_DIR=/var/lib/priks node server.js
```

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `8777` | Порт сервера |
| `HOST` | `0.0.0.0` | Адрес прослушивания |
| `WEB_DIR` | `../web` | Папка со статикой |
| `DATA_DIR` | `./data` | Папка с `store.json` |

## API

Все запросы — `POST` с JSON-телом на `/api/<действие>`.

| Действие | Тело | Ответ |
|---|---|---|
| `register` | `nick`, `password` | `ok`, `nick`, `token` |
| `login` | `nick`, `password` | `ok`, `nick`, `token` |
| `whoami` | `token` | `ok`, `nick` |
| `send` | `token`, `to`, `text` | `ok`, `message` |
| `poll` | `token`, `since` | `ok`, `messages`, `users` |
| `history` | `token`, `with`, `limit` | `ok`, `messages`, `users` |
| `friends` | `token` | `ok`, `friends` |
| `friend-add` | `token`, `nick` | `ok`, `friends` |

Сообщение: `{ id, from, to, text, ts }`. Пустое `to` — общий чат.

Дополнительно: `GET /health` отдаёт состояние сервера.

## ПК-клиент

`bin/priks.exe` — Windows, .NET Framework 4.8. Адрес сервера вводится в поле
«СЕРВЕР» на экране входа. Пересборка — `build.ps1` (нужен `csc.exe` из .NET 4).

## Развёртывание на виртуальной машине

Пошагово: [`deploy/DEPLOY.md`](deploy/DEPLOY.md) — Yandex Cloud, Ubuntu 24.04,
systemd, nginx, HTTPS через certbot.

## Что стоит знать

- Пароли хранятся как SHA256 с солью, сессии — случайные токены в `store.json`.
- Ограничения: ник 2–20 символов (`A-Z a-z 0-9 _ - .`), пароль от 4 символов,
  сообщение до 4000 символов.
- В хранилище держится последние 20 000 сообщений.
- Клиент опрашивает `/api/poll` раз в секунду — WebSocket не нужен.
